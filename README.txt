APPLICATION ANDROID HYBRID WOOD STUDIOS PROJECTION

Ce dossier est le projet source Android.
1. Mettre le site web en ligne.
2. Remplacer https://VOTRE-DOMAINE.com dans MainActivity.kt par l'adresse réelle du site.
3. Ouvrir le dossier android-app dans Android Studio.
4. Générer l'APK/AAB.
5. Pour Google Play, utiliser le fichier AAB et le compte développeur Google Play.

Le paiement automatique et le streaming privé ne sont pas inclus ici : ils doivent être branchés au serveur du site.
Ne mettez jamais les clés secrètes de paiement dans l'application Android.
